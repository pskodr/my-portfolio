## Desk artwork (original)

Every pixel of the desk scene (`public/desk/*.png`) is original artwork, drawn
in code by `scripts/desk-art/` using only Node's built-in `zlib`. No external
images, sprites or textures were used. Rebuild it with `npm run art`.

Objects that refer to real things are drawn as original fan depictions, with no
copied artwork or logos:

| Object | Notes |
|---|---|
| Pikachu | Original sprite-style pixel drawing, seated on the desk. A game sprite the owner supplied was used only as a style reference (flat colour, dark outline, chunky clusters); no pixels were copied. Pikachu is a trademark of Nintendo / Creatures / GAME FREAK / The Pokémon Company; this is a personal, non-commercial reference to the owner's hobby. No official artwork is used. |
| FC Barcelona jersey | Original drawing in the club's colours with the number 8 and the owner's surname, "CHIVATXARANUKUL". No crest, sponsor or kit-maker logo is drawn. |
| Tennis racket | Generic racket in sky-blue tones. No brand marks. |
| Headphones | Original drawing of slim over-ear headphones in space grey with a mesh canopy, drawn from the owner's product reference photo (not traced or copied). No brand marks. |
| Pad Thai, keyboard, mouse, monitor, welcome card | Generic, original. |

## Fonts

Font files are self-hosted from `src/fonts/` through `next/font/local`. Each
folder keeps the font's license file beside it. All three are free under the
SIL Open Font License 1.1, which allows website use and needs no on-page
attribution.

| Font | Use | Source | License |
|---|---|---|---|
| Pixelify Sans (variable, Latin) | Headings, window titles, short buttons, desk labels | `@fontsource-variable/pixelify-sans` 5.2.5 (npm) | OFL 1.1, `src/fonts/pixelify-sans/LICENSE.txt` |
| Geist Mono (variable) | Navigation, labels, body text | `geist` 1.4.2 (npm, Vercel) | OFL 1.1, `src/fonts/geist-mono/LICENSE.txt` |
| Noto Sans Thai (400, 600; Thai subset) | Fallback for Thai characters only (e.g. song titles) | `@fontsource/noto-sans-thai` 5.2.5 (npm) | OFL 1.1, `src/fonts/noto-sans-thai/LICENSE.txt` |

Anything else falls back to the system monospace font.
