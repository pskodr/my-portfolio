# my-portfolio

Phasakorn Chivatxaranukul's portfolio: an interactive pixel-art desk. The
monitor opens the professional portfolio; objects around it open interests.

```bash
npm run dev    # http://localhost:3000
npm run build
npm run art    # redraw the desk artwork into public/desk/
```
